Respawn Delay
================

What this mod does
------------------
Adds an in-game option to control Borderlands 2's general respawn delay.

Presets included for testing and normal play:
- 5 mins
- 1hr
- 3hrs
- Forever

Requirements
------------
1. Borderlands 2 on Windows.
2. The BL2 Python SDK / Willow2 Mod Manager: https://github.com/bl-sdk/willow2-mod-manager

Files in this folder
--------------------
- RespawnDelay.sdkmod
  The packaged mod file.

Install instructions
--------------------
1. Install the Willow2 Mod Manager / Python SDK first:
   https://github.com/bl-sdk/willow2-mod-manager

2. Find your Borderlands 2 install folder on Windows.
   Typical Steam path:
   Steam\steamapps\common\Borderlands 2\

3. Install the mod:
   Copy RespawnDelay.sdkmod.skmod into:
   Borderlands 2\sdk_mods\

5. Start the game and open the mods menu.
   Confirm that:
   - Respawn Delay appears and enable it
