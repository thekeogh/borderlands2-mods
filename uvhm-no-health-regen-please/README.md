# UVHM No Health Regen Please

A small Borderlands 2 PythonSDK mod which disables enemy health regeneration from Ultimate Vault Hunter Mode.

It does not alter enemy levels, game stages, mission rewards, loot, damage, health multipliers, shields, save data, or playthrough state.

## Install

Place `UVHMNoHealthRegenPlease.sdkmod` in your Borderlands 2 SDK mods folder, then enable it in the SDK Mods menu.

## Options

None. The mod is either enabled or disabled.

## Notes

This assumes you are already playing in UVHM. It only removes the UVHM enemy regen behavior.
