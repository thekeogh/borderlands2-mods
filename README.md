# Borderlands 2 / The Pre-Sequel Python SDK mods

This repository is a collection of mods for **Borderlands 2** and **Borderlands: The Pre-Sequel**, built exclusively for the **Python SDK**. See the [BL2/TPS SDK Mod Database](https://bl-sdk.github.io/willow2-mod-db/) for the SDK and other mods. Each mod has its own folder with its documentation and installation instructions.

## Mods

- [OP inflation buster](op-inflation-buster/)  
Keeps Overpower gear and combat difficulty while bringing Borderlands 2 cash values down to roughly level 20.
